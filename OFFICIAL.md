Source: [azahar-emu/azahar 2126.1.2](https://github.com/azahar-emu/azahar/releases/tag/2126.1.2)

## Use

1. Install RetroArch for iOS.
2. Copy `azahar_libretro.dylib` into RetroArch cores.
3. Load a game you dumped from hardware you own, plus `aes_keys.txt` / sysdata.

JIT is disabled on App Store iOS. Use recent iPhones for playable speed.

All-platform official builds: https://github.com/azahar-emu/azahar/releases/tag/2126.1.2
